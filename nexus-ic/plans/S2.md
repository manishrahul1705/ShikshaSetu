## 5. Submit Grievance Integration & Case Plugin Fields

### 5.1 Call Added to `caseService.submitGrievance`
In `server/src/modules/cases/caseService.js`, immediately after the case document is saved and documents linked, append:
```javascript
// Phase S2: Automatic NEXUS ROUTE execution on submission (SPEC 8.1, N18)
const routingResult = await routeCaseOnSubmission(newCase._id);
```
`routeCaseOnSubmission`:
1. Fetches institution details, category, narrative, and evaluates keywords locally for sensitivity.
2. Evaluates active `DEMO-ROUTE-v1` and determines primary bureau, secondary bureau, confidence, and reasons.
3. If confidence < 0.70 or category ambiguous, marks case for manual review (`requiresManualReview: true`, status stays `'REGISTERED'` / pending triage).
4. If auto-routed, creates an immutable `RoutingDecision` record, links `routingDecisionId`, updates `owningBureau: primaryBureau`, sets `status: 'ROUTED'`, initializes `slaClock` segment using `DEMO-CASE-STANDARD-v1` or `DEMO-CASE-PRIORITY-v1`, and sets `analyticStatus: 'PENDING'`.
5. Records audit log `case.routed`.

## 7. Open Questions & Architectural Alignment

1. **Restricted-Handling Roles for Confirmed Sensitive Cases (S25)**:
   - *Design*: Narrative and uploaded evidence of cases with confirmed sensitivity flags are restricted in API responses to:
     - Complainant (own case only)
     - Owning bureau officers assigned to the case
     - Bureau Supervisor
     - Competent Authority
     - Regional Officer (if assigned as secondary / regional inspection)
   - *Strict Rule*: `institution_admin` can **never** view sensitive case narrative or evidence (only sanitized metadata / non-sensitive summary).
2. **DEMO SLA Resolution Targets**:
   - Standard cases (`DEMO-CASE-STANDARD-v1`): Normal priority = 30 days, High = 15 days.
   - Priority cases (`DEMO-CASE-PRIORITY-v1`): Urgent = 7 days.
   - *Confirmation*: Confirmed sensitive cases automatically trigger `DEMO-CASE-PRIORITY-v1` urgent (7-day clock).
3. **Confidence Threshold Cutoff**:
   - Set to `0.70`. Any grievance with jurisdiction confidence < `0.70` or marked with ambiguous flags routes to `/triage` for human triage (supervisor / competent authority), never silently assigned.
4. **Separation of Requester and Approver for Sensitive Flags (S20, U18)**:
   - System auto-flags sensitivity as `SUGGESTED`.
   - If an officer suggests or flags a case as sensitive manually, a *different* officer or supervisor must confirm the flag before restricted handling becomes locked. Self-confirmation is rejected with `403 Forbidden`.
